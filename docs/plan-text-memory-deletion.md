# 연구 방향 전환: 글 기억 삭제 (2026-11-05)

## 왜 바꾸나
- 실제로 일하는 에이전트는 큰 API 모델(Claude, GPT 등)을 쓰고, 가중치(LoRA)를 건드릴 수 없다.
- TMEM 재현에서도 점수 대부분이 "답할 때 글로 보여 준 QA"에서 나왔다 (6문제 기준, 확인 중).
- 그래서 기억은 글(요약, 메모, DB, 벡터 검색)로 두는 것이 현실적이고, 삭제 문제도 거기서 다시 정의한다.

## 연구 질문
에이전트가 일하면서 쌓은 글 기억에서 한 항목을 지우라는 요청이 왔을 때,
**원본만 지우면 충분한가, 아니면 그 내용이 요약본·다른 메모·검색 색인에 새어 남아 있나.**
남아 있다면 어떤 방법이 싸고 정확하게 지우나.

## 기억 구조 (실험할 4종)
| 기억 종류 | 예 | 새는 경로 |
|---|---|---|
| 원본 기록 | 대화 로그, 추출한 QA 목록 | 없음 (지우면 끝) |
| 누적 요약 | 대화가 쌓일 때마다 다시 쓰는 요약 (MemAgent 방식) | 지운 내용이 요약에 섞여 남음 |
| 파생 메모 | 여러 기억을 묶어 쓴 메모·성찰 ("김OO와 박OO는 둘 다 고양이를 키움") | 다른 항목과 엮여 남음 |
| 검색 색인 | 벡터 DB의 임베딩, 키워드 색인 | 원본은 지웠는데 색인·캐시가 남음 |

## 비교할 삭제 방법
| 방법 | 내용 | 비용 |
|---|---|---|
| 원본만 지우기 | 해당 항목만 삭제 | 거의 0 |
| 출처 추적 후 재생성 | 모든 요약·메모가 어떤 원본에서 나왔는지 기록해 두고, 지운 원본을 쓴 것만 다시 생성 | 영향받은 것만큼 |
| LLM으로 전체 검열 | 모든 기억을 LLM이 읽고 해당 내용 제거 | 기억 전체 크기만큼 |
| 정답지 | 그 항목 없이 기억 파이프라인을 처음부터 다시 돌림 | 가장 비쌈 (비교 기준) |

## 평가 (이번 연구에서 만든 것 재사용)
- 지운 사실이 아직 나오는지: 직접 질문, 바꿔 묻기, 간접 추론 질문 ("고양이 키우는 사람 다 말해 줘")
- 남겨야 할 기억 정확도, 상식 유지
- 비용: 토큰 수, 시간
- 모두 정답지와 비교. 답 유형 분류(그대로 나옴 / 다른 사람 답 / 모른다) 재사용

## 데이터와 모델
- 데이터: 지금 쓰는 가짜 인물 스트림(겹치지 않는 답) + LongMemEval 대화 세션
- 에이전트 모델: 사내 GPU에서 공개 모델(Qwen3 계열)을 vLLM으로 돌림. 필요하면 OpenGateway로 큰 API 모델 비교
- GPU: worker-6000pro-2 GPU 4번 (점유 기간 안에서)

## 이미 있는 것 / 이어서 할 것
- 진행 중: TMEM 재현 (QA 글 보여 주기, 기억 켜고/끄고). 끝나면 "글 vs 가중치" 결론을 정리해 가중치 연구는 마무리
- 가중치 연구 결과(삭제 실험, decoy)는 사내 보고서와 workshop 초안으로 남긴다
- 선행 연구 조사는 ARS로 다시 한다 (글 기억 삭제, RAG unlearning, 요약에서의 정보 누출)
