# 가중치(LoRA) 기억 삭제 연구 마무리 보고서

- 작성: 2026-11-05, khope (Claude Code 보조)
- 저장소: github rlaope/tmem-repro (private). 결과 파일 `runs/gpu/`, 재현 코드 `scripts/`
- 기반 논문: TMEM, *Scaling Self-Evolving Agents via Parametric Memory* (arXiv 2606.04536). 공개 코드 없음, 재구현

## 1. 한 줄 결론

LLM 에이전트가 공유 LoRA에 쌓은 기억 하나를 "그 기억이 바꾼 양을 빼서" 지우는 것은 **된다**. 다만 남은 기억이 조금 망가지고(원인: 모든 기억이 공유하는 공통 성분), decoy 방식으로 절반까지 줄일 수 있다. 그러나 **논문의 성능 자체가 가중치 기억이 아니라 메모(글)에서 나오는 것으로 확인**되었고, 실제 에이전트는 가중치를 못 건드리는 API 모델을 쓰므로, 이 방식은 회사 제품에 맞지 않는다. 연구는 **글 기억 삭제**로 전환한다.

## 2. 질문과 답

| 질문 | 답 | 판정 |
|---|---|---|
| 빼기로 기억 하나가 지워지나 | 지운 기억 정답률 0~1% = 정답지(처음부터 안 배움)와 같음. 다시 가르칠 때 정답지보다 느림 → 숨은 흔적 없음 | ✅ |
| 남은 기억은 무사한가 | 정답률 10%p 하락, NLL +0.21. 무관한 사람(decoy)의 변화량을 빼도 같은 손상, 무작위 방향은 손상 없음 → 공통 성분이 원인 | ⚠️ |
| 손상을 줄일 수 있나 | 같은 시점 decoy 방향 성분을 남기고 빼면 +0.21 → +0.09, 정답률 하락 10%p → 7%p. 다른 기억들의 평균 방향은 효과 없음 | ✅ 절반 |
| 지운 뒤 뭐라고 답하나 | "모른다"가 아니라 다른 사람의 답을 가져옴 (12개 중 10~12개) | ⚠️ |
| 논문 점수(F1 41.2)는 재현되나 | 논문 설정 그대로 9.8. 뽑은 QA를 메모로 프롬프트에 붙이면 27.8(가중치 끔)~30.9(켬). 가중치 기여는 +3 | ❌ 논문 본문 조건으로는 재현 안 됨 |

## 3. 실험 설정

- 모델: Qwen3-4B (일부 0.6B). LoRA rank 6, 마지막 8층 FFN (논문 4층), SGD
- 데이터: 가짜 인물 81명 × 사실 4개 (답은 실제 단어, 스트림 안에서 겹치지 않음). 기억 하나 = 인물 1명
- 논문 설정(lr 5e-4, 5 epochs, 단어 답)으로는 저장 안 됨 → 문장 답, 질문 4표현, 일반 QA 8개 섞기, lr 1e-3, 10 epochs로 변경
- 복습: 새 기억마다 옛 기억 QA 32개를 같이 학습. 없으면 2개만 지나도 옛 기억 0%; 있으면 4~7개 전 50%, 16개 이상 전 69% (상식 0.85 → 0.75)
- 삭제 대상 k=16, 뒤에 배운 기억 수 m ∈ {0,1,2,4,8,16,32,64}, seed 3개
- 정답지(oracle): k 없이 처음부터 다시 학습. 대조군: 무작위 방향 빼기, decoy 빼기, 같은 실행 반복(노이즈 0 확인)

## 4. 주요 수치

### 4.1 삭제 (4B + 복습 32, 3 seed 평균)

| m | 지운 기억 정답률 학습 직후 / 빼기 / 정답지 | 앞 기억 정답률 빼기 / 정답지 | 손상(NLL 차) 빼기 | 손상 decoy 빼기 | 손상 무작위 |
|---|---|---|---|---|---|
| 1 | 58 / 0 / 0% | 50 / 62% | +0.10 | +0.10 | 0.00 |
| 8 | 58 / 0 / 0% | 48 / 58% | +0.41 | +0.38 | +0.06 |
| 64 | 75 / 8 / 0% | 69 / 69% | +0.04 | +0.02 | −0.06 |

### 4.2 삭제 방식 비교 (m 1~16 평균)

| 방식 | 지운 기억 | 앞 기억 정답률 | 손상(NLL 차) |
|---|---|---|---|
| 정답지 | 0% | 62% | 0 |
| 전체 빼기 | 0% | 52% | +0.21 |
| decoy 방향 남기고 빼기 | 0% | 55% | +0.09 |
| 평균 방향 남기고 빼기 | 0% | 52% | +0.21 |

### 4.3 논문 재현 (LongMemEval-S 앞 50문제, 1회)

| 방법 | F1 | EM | 논문 |
|---|---|---|---|
| 기억 없음 | 8.4 | 0.0 | 5.30 / 0.00 |
| 가중치 기억만 (논문 설정) | 9.8 | 6.0 | 41.24 / 25.54 |
| 가중치 기억만 (학습 2배) | 5.2 | 2.0 | – |
| QA 메모 붙임, 가중치 끔 | 27.8 | 18.0 | – |
| QA 메모 붙임 + 가중치 | 30.9 | 18.0 | – |

논문은 답변 프롬프트를 싣지 않았고, 본문(식 6)은 "글은 넘기지 않는다"고 하나 그림 설명은 "검색된 기억 QA 쌍"이라고 적음. 실제 조건은 메모를 붙인 쪽에 가까운 것으로 추정. 남은 10점 차이는 미확인 (문제 수 50 vs 500, 프롬프트, 디코딩).

## 6. 한계

- 모델 1개(4B), seed 1~3, 재현 50문제 1회. 논문은 500문제 3회
- 합성 데이터(가짜 인물). 실제 대화 데이터에서는 decoy가 지울 기억과 겹칠 수 있음 (미확인)
- 남은 손상 절반의 원인, decoy가 시간이 지나 낡는 문제(m이 클수록 효과 감소 경향), 쓰기 비용 2배는 미해결
- 복습은 QA 글 전체를 보관해야 가능 → 그 글을 프롬프트에 붙이는 것만으로 가중치 기억보다 높은 점수
